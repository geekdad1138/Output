MIT is using VLASH to help predict the future!

In robotic systems there is a methodology called Vision Language Action (VLA) where Vision systems are hooked up to Language processors linked to motion Action systems.

This differs from traditional industrial robotics vision systems that go through training to identify strict parameters for items for the vision system to recognize.

So if a robot needs to pick up a coffee cup, as long as the cup hasn’t changed, the original system is very fast and efficient. But if someone changes the size or shape, it may fail.

And with a language system for VLA, it can even handle more dynamic instructions like “pick up the coffee cup by the handle.”

VLA offers more dynamic, flexible instructions, but with that there is a speed trade off for that “thinking” step.

MIT worked on a prediction system that helps speed things up by thinking about the next step while working on the current one.

From MIT News:
“The MIT researchers developed a new system called VLASH that enables a VLA to predict the future state of the robot and its environment. It uses this information to plan the next set of motions while the robot is completing the current action chunk.”

The project is being led by researchers Song Han, Jiaming Tang, and Yufei Sun.

It still may be difficult to beat the speed of a rigid system with an unchanging environment, but with VLA and VLASH, the speed is catching up and offering the benefits of more flexible automation in a dynamic work environment.

And my favorite part?
They are training the robots to fold clothes.
